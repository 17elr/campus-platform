# 路线图与当前边界

## 已实现

注册登录、物品发布审核、留言、演示交易、推广佣金、独立配送、配送员审核、履约纠纷、广告管理、独立公告服务、Redis 公告缓存、可选 RabbitMQ 配送日志。

## 后续方向

真实支付与结算；JWT 密钥及撤销状态持久化；对象存储；审计日志可靠投递；接口权限与参数校验统一；可移植回归测试、自动化流水线和部署监控。

## 当前限制

支付为演示；JWT 依赖进程内状态；图片为本地存储；公告依赖 Redis 和公告服务，无自动降级；消息发送失败只记录警告，没有日志必达保证；部分验收脚本依赖本机路径与演示数据。当前未声称具备生产级高可用或完整自动化测试覆盖。
